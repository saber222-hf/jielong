# 接龙管家 · 志愿抢报助手

一个纯前端的单文件网页应用，用于在「接龙管家」的报名接龙开放瞬间自动提交报名。

- 无需后端、无需安装，打开网页即用
- 可「添加到主屏幕」，像 App 一样使用
- 所有数据（账号令牌、目标岗位）只保存在各自设备的浏览器本地

## 功能

- **多账号扫码登录**：用微信扫码登录（手机可截图后用微信「扫一扫 → 相册」选图），不挤手机微信；可保存多个账号切换
- **粘贴接龙链接**：支持 `https://jielong.com/s/...`、`#小程序://接龙管家/xxx`、`i.jielong.com/fb/xxx`、纯短码
- **获取岗位列表**：自动解析接龙，列出全部岗位并标注「已抢 / 可抢」，直接勾选目标
- **定时开放自动抢**：接龙未开放时自动等待，到点毫秒级直接提交（不打开小程序页面）
- **启用开关**：随时开始 / 暂停
- **自动模式**：粘贴链接后自动获取岗位、自动选中已保存的目标、自动开抢

## 使用

1. 打开网页，点「扫码添加账号」登录
2. 粘贴接龙链接 → 点「获取岗位列表」（或开启自动模式后自动完成）
3. 勾选想要的时间段（按优先级从上到下）
4. 打开右上角开关，等待/开抢
5. 抢到会弹窗提示并自动停止

> 运行时请让页面**保持在前台、不要锁屏**。若开放时间在数小时后，建议在电脑浏览器上挂着，手机可能被系统暂停。

## 部署

本目录即完整的静态站点，可直接托管：

- **Netlify**：连接 GitHub 仓库，`Build command` 留空，`Publish directory` 填 `.`
- **GitHub Pages**：仓库 Settings → Pages → 选择分支根目录即可（已含 `.nojekyll`）
